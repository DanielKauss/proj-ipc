# Uso

Si se ha descargado el proyecto de github, añadir una carpeta llamad "lib" al directorio base, 
que incluya las librerias de poliformat, y una carpeta javafx con todos los jars de javafx. Despues añadir 
una libreria llamada "JAVAFX" con los jars y binarios necesarios.
